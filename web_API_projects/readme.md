# Web API Projects
 
A collection of small projects for practicing how to work with web APIs — sending requests, handling responses, and using the returned data in real programs.
 
## Purpose
 
Each subfolder is a self-contained project that connects to a different public API. The goal is to get comfortable with:
 
- Making HTTP requests (usually with Python's `requests` library)
- Reading JSON responses
- Handling API keys and authentication (where required)
- Using the data in something practical (GUI, script, automation, etc.)

 
Each project folder has its own `README.md` describing what it does and which API it uses.
 
## Note
 
- Keep each API project in its own folder.
- Include a short README per project (what the API does, any setup/API key needed, how to run it).
- Note down rate limits or authentication requirements for each API you use, so you don't hit surprises later.
